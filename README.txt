KEN TANK IMPROVED WEBSITE — VERSION 2

IMPORTANT IMAGE NOTE:
The current site uses:
- Ken Tank's own tank image at https://kentankkenttainers.com/kentank1.jfif

The HTML in this ZIP points to those existing image URLs so the original visuals appear without inventing replacement images. If you own/licence local copies of those images, put them in assets/images and update the src paths before publishing.
